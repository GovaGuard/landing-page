## Brand & Style Guidelines

### Color Palette

```
Primary Colors:
- Cyan: #00D9FF (electric blue, high-tech accents)
- Green: #00FF88 (neon green, success states, growth indicators)

Backgrounds:
- Dark Navy: #0A1628 (primary background)
- Deep Black: #000000 (secondary background)
- Charcoal: #1A1A2E (tertiary background)

Supporting Colors:
- White: #FFFFFF (text, labels)
- Light Gray: #E0E0E0 (secondary text)
- Medium Gray: #808080 (dividers, subtle elements)
- Warning Orange: #FF6B35 (risk indicators, cost warnings)
```

### Style Characteristics

- **Aesthetic**: Cyber-tech intelligence briefing
- **Visual Elements**: Terminal windows, grid overlays, scanlines, hexagonal patterns
- **Typography**: Monospace fonts for technical elements, sans-serif for body
- **Contrast**: High contrast for readability (light on dark)
- **Iconography**: Minimalist, geometric, technology-focused
- **Data Visualization**: Clean, professional charts with glowing accents

### Technical Specifications

- **Web Display**: 800px width minimum
- **Print Quality**: 300 DPI
- **Preferred Format**: SVG (scalable, crisp)
- **Acceptable Format**: PNG (transparent backgrounds)
- **Aspect Ratios**: 16:9 for charts, 4:3 for diagrams, custom for tables
- **File Naming**: Sequential numbering (01-29) with descriptive names

## Recommended AI Tools

### DALL-E 3 (OpenAI)
- **Best For**: Conceptual illustrations, cover designs
- **Strengths**: Understanding complex prompts, artistic interpretation
- **Limitations**: Less precise for data charts

### Midjourney
- **Best For**: Stylistic consistency, high-quality renders
- **Strengths**: Cyber-tech aesthetic, futuristic designs
- **Limitations**: Requires Discord, less control over exact layouts

### Adobe Firefly
- **Best For**: Professional business graphics
- **Strengths**: Commercial licensing, Adobe integration
- **Limitations**: May be too conservative for cyber-tech style

### Canva (AI + Templates)
- **Best For**: Charts, tables, data visualizations
- **Strengths**: Precise control, easy editing, export options
- **Limitations**: Less artistic for conceptual illustrations

### Alternative Tools
- **Chart.js / D3.js**: Code-based chart generation
- **Figma**: Manual design with full control
- **Visme/Venngage**: Infographic and presentation tools

---

## Generation Tips

### For Charts & Graphs
1. Use Canva or Chart.js for precise data visualization
2. Export as SVG for scalability
3. Apply color palette manually after generation
4. Add grid overlays in post-processing

### For Technical Diagrams
1. Start with wireframe sketches
2. Use Figma or draw.io for complex matrices
3. Apply cyber-tech styling as final layer
4. Ensure all text is legible at 800px width

### For Conceptual Illustrations
1. Use DALL-E 3 or Midjourney for artistic elements
2. Iterate on prompts 3-5 times for best results
3. Combine AI output with manual touch-ups
4. Maintain consistent lighting and perspective

### For Tables & Matrices
1. Build in Canva or Google Sheets first
2. Export as image with transparent background
3. Add glow effects and styling in Photoshop/GIMP
4. Ensure readable fonts (minimum 12pt)

### Consistency Checklist
- [ ] Color palette matches brand guidelines
- [ ] Cyber-tech elements present (grids, scanlines, glows)
- [ ] All text is readable on dark backgrounds
- [ ] File format is SVG or high-res PNG (300 DPI)
- [ ] Naming convention follows sequential pattern
- [ ] Visual style matches other assets in set

### Common Pitfalls & Solutions

**Problem**: AI-generated text is illegible or misspelled
**Solution**: Generate image without text, add text manually in Photoshop/Illustrator

**Problem**: Colors don't match brand guidelines
**Solution**: Use color adjustment layers in Photoshop (Hue/Saturation, Color Balance)

**Problem**: Chart data is incorrect
**Solution**: Use Canva or Chart.js for data accuracy, then apply styling

**Problem**: Cyber-tech aesthetic is too aggressive/distracting
**Solution**: Reduce opacity of overlays to 10-20%, use subtle glows

**Problem**: SVG file size is too large
**Solution**: Optimize with SVGO tool or convert complex SVGs to PNG

**Problem**: Print quality is poor (blurry when printed)
**Solution**: Ensure 300 DPI for PNG exports, use vector (SVG/PDF) where possible
